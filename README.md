# shots-design-basing-on-CRS
基于共反射点的炮点优化设计及实现
一、 软件简介
本软件基于二维射线追踪方法，以目的层共反射点（CRP）为目标。通过正演模拟计算地下目的层的有效覆盖次数，同时通过反演反算实现该覆盖所需的炮点分布（Count）。
软件会自动识别炮点反演需求密集的区域（Dense，需加密激发） 与炮点反演需求稀疏的区域（Sparse，可适当抽稀）。在控制总炮数不变或微增（默认上浮5%）的前提下，软件输出优化后的炮点坐标（shot_opt.csv），并最终对比优化前后的地下覆盖次数，指导野外采集施工设计。
二、 快速操作流程
1. 全自动模式（推荐）
选择输出目录：点击顶部工具栏的【输出目录】，选择用于保存结果的文件夹（必须选择，否则无法计算）。
输入文件与参数：在【模型】页签中，依次通过【选择】按钮导入文件：
第一层、第二层界面文件（.txt）。
炮点文件（.txt）、检波点文件（.txt）。
(可选) 若为三层模型，勾选【启用第三层】，选择第三层文件，并输入 v4 速度。
预览模型：点击【预览模型】，在右侧图框检查地层形态是否正确，日志区会提示模型检查结果。
一键运行：点击顶部工具栏的【自动优化】。此时顶部日志区会实时滚动显示进度。
查看结果：
反演+优化：查看反演 Count 并列柱状图及红绿门槛线，软件已自动生成并保存 shot_opt.csv。
对比：查看优化前后的地下覆盖次数（Fold）曲线对比。
日志区：查看关键低覆盖盲区优化前后的数值提升。
2. 手动优化模式（局部验证/自定义炮点）
若您已有一套设计方案，想验证其效果：
先跑一次【自动优化】（为了让软件建立基础模型并计算原设计覆盖）。
在【反演+优化】点击【输入手动优化炮点】，选择您自己设计的炮点文件。
点击顶部工具栏的【手动优化】。软件会将您的炮点按设定炮距重新网格化吸附，直接计算该方案下的地下覆盖次数并生成对比图。
三、 主要参数说明
1. 观测系统参数
道距：默认 25 m。检波点间距。决定最终剖面反射点的面元大小（计算时面元为道距一半）。
炮距：默认 100 m。炮点间距。自动优化生成的炮点网格步长，以及手动优化重采样所吸附的基准网格。
最大偏移距：默认 2500 m。射线追踪时允许的最大激发-接收距离，超过该距离的射线将被丢弃。
2. 稀疏计算参数（降采样）
为了大幅提高运算速度，软件会自动对模型进行网格抽稀（粗采样）。层数不同，抽稀倍数自动适配。
面元放大倍数：默认 两层 4 / 三层 8。正演时 CRP 点的间隔放大倍数。倍数越大，计算越快，但覆盖曲线越平滑。
炮距放大倍数：默认 两层 2 / 三层 4。计算时参与运算的炮点疏密程度（仅用于中间计算，不影响最终生成的实际炮点）。
道距放大倍数：默认 8。计算时参与运算的检波点疏密程度。
3. 优化参数（炮点加密与稀疏判定）
反演炮数权重 (cntWeight)：默认 3。反演 Count（柱子高低）在加密决策中的重要性。 数值越大，越倾向于在反演炮数需求大的地方加密。
覆盖次数变化影响 (foldTargetOffset)：默认 4。目标覆盖门槛。系统取满覆盖段中位数值减去该值，作为判定覆盖是否达标的基础线。该值越大，Dense 区域越少。
炮点数量控制 (nmaxFactor)：默认 1.05。总炮数上浮上限。表示允许优化后的炮点总量最多是原设计的多少倍（1.05 即上浮5%）。
加密门槛 (denseThrHi)：默认 1.05。Dense（炮点密集）判定阈值。反演出的加权平滑炮数（Count）高于局部基准值的该倍数时，判定为“炮点需求密集区”，需加密激发。
稀疏门槛 (denseThrLo)：默认 0.95。Sparse（炮点稀疏）判定阈值。反演出的加权平滑炮数（Count）低于局部基准值的该倍数时，判定为“炮点需求稀疏区”，可适当抽稀。
4. 炮点步长参数
炮点Dense步长：默认 50 m。在判定为“需加密”的区域，炮点的布设间距。
炮点Sparse步长：默认 200 m。在判定为“可稀疏”的区域，炮点的布设间距。
炮点Normal步长：默认 100 m。在“正常”区域，炮点的布设间距（通常与原始炮距一致）。
(注：不同层的反演 Count 权重，软件默认采用“最深层为1.0，浅层按深度比例折算”的策略，无需手动设置，确保加密重点始终照顾深层目的层。)
